# Modulo_3_TyHMI

En este módulo nos introdujimos en el uso de Simul8, un software avanzado de simulación de eventos discretos, aplicando sus herramientas fundamentales para el modelado, análisis y optimización de sistemas productivos.

A lo largo del proyecto, desarrollamos una simulación propia basada en un proceso de manufactura continuo (molienda, clarificación, cristalización y centrifugado).
